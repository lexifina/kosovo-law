# Neni 90
Punësimi në Shërbimin Civilë të Komunës duhet të mbikëqyret dhe rregullohet nga Udhëheqësi i Personelit, për të siguruar që Shërbimi Civilë reflekton proporcion të drejtë profesional, gjinor dhe etnik. Shërbimi Civilë Komunal si tërësi, duhet që të përmbajë proporcion të drejtë të përfaqësimit të personave me aftësi të kufizuar.
