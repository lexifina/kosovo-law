# Neni 38
Shqyrtimi përmbajtjesor i aplikimit për
Certifikatën për Mbrojtje Plotësuese
1. API e shqyrton aplikimin, në përputhje me kushtet përmbajtësore, në përputhje me nenin 86 dhe 90 të Ligjit përkatës, për të konstatuar nëse;
1.1. produkti për të cilin aplikimi për certifikatë është i mbrojtur me patentë bazë;
1.2. autorizimi për plasimin e produktit në treg jepet në përputhje me rregulloret e veçanta përkatëse;
1.3. produkti tashmë nuk është objekt i ndonjë certifikate;
1.4. autorizimi nga nën-paragrafi 1.2 i këtij paragrafi është autorizimi i parë për plasimin e produktit në treg.
2. Nëse API konstaton se janë plotësuar kushtet e parapara, atëherë API nxjerr vendim për dhënien e certifikatës.
3. Nëse API konstaton se nuk janë plotësuar kushtet e përcaktuara, mund të refuzojë me vendim aplikimit për Certifikatë.
4. Paragrafët 1 deri 3 të këtij neni vlejnë edhe për aplikimet për zgjatjen e kohëzgjatjes.
