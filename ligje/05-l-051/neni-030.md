# Neni 30
Ekzaminimi i aplikimit
1. API kontrollon nëse aplikacioni i parashtruar përmban të gjitha dokumentet e kërkuara sipas nenit 23 të këtij ligji dhe nxjerr vendim në afat prej gjashtëdhjetë (60) ditësh.
2. Nëse API konstaton se aplikacioni nuk përmban të gjitha dokumentat e nevojshme në bazë të nenit 23 të këtij ligji, API fton personin që aplikon të korrigjoj aplikacionin brenda gjashtëdhjetë (60) ditësh.
3. Me kërkesës së aplikuesit, e cila duhet të bëhet brenda afatit të caktuar kohorë të referuar në paragrafin 2 të këtij neni, afati kohor mund të zgjatet për maksimum tridhjetë (30) ditë duke llogaritur që nga data e skadimit të atij afati.
4. Nëse personi që aplikon nuk e korrigjon aplikacionin e tij bazuar në ftesën e API –së apo dështon të korrigjoj atë brenda afatit te përcaktuar , aplikacioni do të refuzohet.
