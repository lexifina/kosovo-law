# Neni 55
Revokimi i regjistrimit të një përdoruesi të autorizuar
Nëse API vërteton se përdoruesi ka pushuar të përmbush të gjitha kriteret e përcaktuara për dhënien e të drejtës së përdorimit të një emri të mbrojtur të origjinës apo treguesi gjeografik, API do të marr vendim për revokimin e regjistrimit të një përdoruesi të autorizuar pas përfundimit së procedurës për revokim në API.
