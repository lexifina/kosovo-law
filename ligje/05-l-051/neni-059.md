# Neni 59
Anulimi i të drejtës së përdorimit
Vendimi për regjistrimin e përdoruesit të autorizuar anulohet nëse API vërteton se gjatë zhvillimit të procedurës, në kohën e plotësimit të aplikacionit për regjistrim të një përdoruesi të autorizuar, kushtet për mbrojtje nuk ishin plotësuar sipas kërkesave të këtij ligji.
