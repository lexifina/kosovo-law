# Article 124
Traffic rules for cyclists
1. The driver of the bicycle (hereinafter: cyclist), must use the bicycle track or the common path for bicycles and pedestrians.
2. The cyclist when using the common path for bicycles and pedestrian should be careful and should give priority to pedestrians.
3. When there is no bicycle lane-track or common path for bicycles and pedestrians, cyclist must use the jetty and if this is not possible, he should use the right track and should move as close as possible to the right edge of the road up to one (1) m.
4. For an offense, shall be punished by a fine of twenty (20) euro, the cyclist that acts in contradiction to the provisions of this Article.
