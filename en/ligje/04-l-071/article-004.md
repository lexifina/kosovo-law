# Article 4
Address elements
1. Elements of an address are as following:
1.1. name of the municipality;
1.2. name of the village;
1.3. name of the public circulation area to which the object has an exit;
1.4. number of the building;
1.5. entrance number;
1.6. floor number;
1.7. apartment number; and
1.8. postal code.
